# 첫 공개 배포 구성

아직 공개 배포되지 않았다. 로컬 검증을 마친 코드와 서버 설정을 준비한 상태다.

- 웹: 기존 Vercel `take-the-l` 프로젝트, 저장소 루트 `web`, Node.js 22.
- 게임 서버: 서울 리전 EC2 `t4g.micro` 한 대, ARM, 2 vCPU / 1 GiB RAM.
- 디스크: 암호화된 8 GiB gp3 한 개. 인스턴스 종료 시 삭제된다.
- 네트워크: 고정 공인 IPv4 한 개, HTTPS/WSS 프록시. 2567 포트를 외부에 열지 않는다.
- 방: 5개 고정, 각 20명. 자동으로 서버를 늘리지 않는다.
- CPU 크레딧: Standard 모드로 CPU 크레딧 추가 요금을 방지한다. 크레딧이 부족하면 처리 속도가 제한된다.
- 운영: `playground.service`로 자동 재시작하고 Caddy로 인증서를 관리한다. 닉네임과 이동 기록은 영구 저장하지 않고 집계만 기록한다.

## 비용

2026-09-30 AWS Pricing API에서 서울 Linux `t4g.micro`의 시간당 단가를 $0.0104로 확인했다. 월 730시간 가정 시 서버 $7.592, 공인 IPv4 $3.65이며 디스크를 더한 기본 비용은 월 약 $12다. 세금, 환율, 추가 데이터 전송 비용은 별도다. 무료 혜택은 확인되지 않아 비용 계산에서 제외했다.

AWS 계정 전체에 월 $17 비용 예산을 만들었다. 실제 비용 50% / 80% / 100%, 예상 비용 100%에서 사용자가 지정한 이메일로 알린다. 원화 3만 원의 고정 상한이 아니며 자동 차단 기능도 없다. 계정의 다른 서비스 비용과 이번 달에 이미 사용한 비용도 포함된다.

## 공개 전 마지막 단계

1. 배포 보류 해제 및 위 구성의 실제 리소스 생성 승인을 받는다.
2. 전용 보안 그룹, EC2와 공인 IP를 만들고 `deploy/bootstrap.sh`로 준비한다.
3. 빌드된 서버와 잠금 파일을 복사하고 운영 의존성을 설치한다.
4. 서버 환경 변수와 HTTPS 호스트를 설정하고 `playground.service` / `caddy.service`를 시작한다.
5. Vercel의 `NEXT_PUBLIC_GAME_SERVER` / `NEXT_PUBLIC_SITE_URL`을 설정하고 배포한다.
6. 공개 HTTPS 주소에서 두 명의 입장·이동·춤·말풍선과 브금·음소거를 확인한다. 실제 휴대폰 확인은 별도로 진행한다.

## 종료할 때

서버 종료와 공인 IP 반납은 별도 작업이다. 인스턴스만 종료하면 남은 공인 IP에 비용이 계속 발생할 수 있다. 집계가 필요하면 `server/data/stats.json`을 먼저 보관한다. 서버 종료 시 8 GiB 디스크도 삭제된다.

관리용 개인 키와 환경 변수는 Git에 포함하지 않는다. 자동 생성된 비용 알림은 서버 종료 후에도 유지할 수 있으며 서버를 자동으로 중지시키지는 않는다.
