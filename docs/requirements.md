# Take the L — 첫 공개 범위

## 놀이터

- [x] 닉네임만 입력하면 로그인 없이 1~5번 공개방 중 사람이 있는 여유 방에 입장한다.
- [x] 닉네임은 처음 접속할 때 랜덤으로 채워두고 원하는 사람만 수정한다.
- [x] 방별 인원을 보고 이동할 수 있고, 각 방의 목표 정원은 20명이다.
- [x] 현재 방을 친구에게 공유하는 링크를 복사할 수 있다.
- [x] 입장마다 독자적인 블록 캐릭터의 색과 모양을 랜덤으로 정한다. 꾸미기는 없다.
- [x] PC 방향키와 모바일 가로 화면의 가상 조이스틱으로 이동한다.
- [x] Q/W/E/R/T 또는 모바일 버튼으로 다섯 춤을 춘다. 같은 춤 버튼이나 이동으로 춤을 멈춘다.
- [x] 춤 시작 때 사용자 녹음이 한 번 재생되고, 가까운 사람 소리만 제한적으로 들린다. 음소거할 수 있다.
- [x] 자체 제작한 브금을 입장부터 반복 재생한다. 녹음 재생 중에는 브금 볼륨을 줄이고, 음소거·퇴장·백그라운드 전환 시 소리를 멈춘다.
- [x] 정해진 말풍선으로만 소통한다. 닉네임 길이와 내용은 제한한다.
- [x] 접속이 끊겼다가 돌아오면 같은 방을 복구하도록 시도한다.

## 공개와 운영

- [x] `L을 가져가`, `엘을 가져가`, `Take the L`을 설명하는 검색 가능한 페이지를 만든다.
- [ ] 메타데이터, 공유 이미지, robots.txt, sitemap.xml을 준비하고 Search Console 등록을 확인한다.
- [x] 입장 세션, 최대 동시 접속, 첫 춤, 춤별 실행 수, 공유 클릭을 집계한다.
- [x] 사용자별 이동 기록이나 분석용 닉네임은 저장하지 않는다.
- [ ] Vercel에 웹, AWS에 게임 서버를 배포한다.
- [ ] 월 허용 비용 3만 원에 맞춰 무료 혜택과 비용 알림을 확인한다.
- [ ] PC와 모바일에서 두 명 이상이 서로의 이동·춤·말풍선을 볼 수 있는지 확인한다.
- [ ] 오픈채팅방에 처음 공유한 때부터 1시간간 방 입장 세션 100개를 성공 기준으로 측정한다.

## 범위 밖

- 자유 채팅, 계정, 캐릭터 꾸미기, 방 생성, 랭킹, 퀘스트, 원본 영상·음성 재사용.
- 3,000명 동시 수용과 Google 검색 1위 보장.
